# Topic clusters

TodayAI already has an AI editorial spine and an AI tools directory. The recommended clusters connect articles, tools, games and existing search without changing legacy article URLs.

## Cluster map

### AI productivity

Pillar: AI tools for everyday work and study

Supporting pages: AI email writer, prompt improver, flashcard generator, student workflows, meeting-note guidance.

Internal links: `/ai-tools`, `/tools`, relevant guides, newsletter.

### AI automation

Pillar: practical AI workflows for small teams

Supporting pages: n8n vs Make, workflow planner, automation safety, repeatable admin tasks.

Commercial paths: clearly disclosed software links and sponsorships only after editorial qualification.

### AI coding

Pillar: understanding and evaluating coding assistants

Supporting pages: code explainer, dated comparison tests, model release coverage, developer guides.

Trust requirements: exact test prompts, dates, model versions and limitations.

### AI documents and communication

Pillar: turning long or difficult text into useful next steps

Supporting pages: PDF summarizer, email writer, document privacy guide, citation and review guidance.

### AI games and learning

Pillar: play with visible AI behavior

Supporting pages: human-or-AI, word detective, drawing recognition, explanatory articles about datasets and model uncertainty.

## Editorial rules

- Every comparison must record the tested date and versions.
- Every AI-generated result must be labelled as generated and reviewed for safety.
- Tool pages must explain input handling, limits, availability and failure states.
- No cluster should exist solely to capture a keyword; each page must answer a real user need.
