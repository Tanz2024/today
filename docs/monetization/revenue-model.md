# Revenue model

This is a strategic model, not a forecast. No traffic, RPM, conversion or revenue figures are asserted.

## Order of operations

1. Restore reliable access and publish genuinely useful content.
2. Use clearly labelled AdSense placements only on content that remains usable with ads.
3. Add affiliate links only where the recommendation is relevant, tested or transparently sourced, with `sponsored` links and disclosure.
4. Consider sponsorships only with editorial separation and visible labelling.
5. Consider paid AI usage later, behind configuration and explicit approval; no payment gateway is included in this phase.

## Cost model for future AI tools

For each tool, record:

`cost per 1,000 requests = provider input cost + provider output cost + infrastructure cost + storage/egress cost`

The calculation must state token assumptions, average input size, average output size, cache hit rate, failure/retry rate and unknowns. Until a provider/model is selected, all such values remain unverified.

## Guardrails

- Do not use advertising to compensate for unreliable product behavior.
- Do not sell access to a tool whose provider, privacy or retention behavior is undocumented.
- Do not report third-party pricing as TodayAI revenue.
